# 新竹市東區三民國小｜學生輔導專區 V1.0

這是一個以 HTML、CSS、JavaScript 製作的靜態網站原型，預計獨立部署至 Netlify，再由學校官方網站的輔導處頁面連結進入。

## 專案內容

- `index.html`：頁面結構與內容
- `styles.css`：視覺樣式、響應式版面與無障礙焦點樣式
- `script.js`：手機導覽選單、心情小氣象互動、頁尾年份
- `images/`：放置經授權的圖片素材
- `documents/`：放置經核定且適合公開的文件

## 本機預覽

1. 將 ZIP 解壓縮。
2. 進入 `sanmin-student-counseling-v1` 資料夾。
3. 直接以 Chrome、Edge 或 Firefox 開啟 `index.html`。
4. 測試導覽列、情緒互動及不同螢幕寬度。

建議使用 Visual Studio Code 開啟整個資料夾，並安裝 Live Server 擴充功能。按下 `Go Live` 可用本機伺服器預覽。

## GitHub 與 Netlify 部署

1. 在 GitHub 建立新儲存庫，例如 `sanmin-student-counseling`。
2. 將本資料夾中的檔案上傳到儲存庫根目錄。
3. 登入 Netlify，選擇新增專案並匯入現有 Git 儲存庫。
4. 授權 Netlify 讀取該儲存庫，選擇 `main` 分支。
5. 此原生靜態網站不需要建置指令；發布目錄設為儲存庫根目錄。
6. 執行部署，測試 Netlify 提供的公開網址。
7. 經校方審核後，再由學校官方網站的輔導處頁面加入連結。

## 正式公開前的必要檢查

- 確認學校名稱、電話、地址、處室人員與職掌等資訊。
- 確認所有計畫、會議資料與文件都經核定且適合公開。
- 確認求助專線、服務內容、時間及外部資源連結均以官方資訊核實。
- 不得上傳學生個案、晤談紀錄、敏感個資或未取得授權的照片。
- 請校方確認網站發布、網域使用與個資保護規範。
- 由負責人定期檢查連結、文件與聯絡資訊是否過期。

## 注意

此版本是網站原型，不代表校方已核定所有文字與資訊。頁面中標示「待補」的內容，必須在確認後才更新。心情小氣象只提供一般自我覺察建議，不提供診斷，也不會儲存或傳送使用者選擇。
